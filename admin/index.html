Monetization
Google AdSense. Ads stay fully off until a publisher ID is set here.

Before you paste an ID here

1. Apply at google.com/adsense with this site's real URL — that requires your own Google account and payout details, which only you can provide.
2. Wait for Google's review and approval (their process, their timeline — this can take days to weeks).
3. Once approved, copy your Publisher ID (looks like ca-pub-1234567890123456) from your AdSense account and paste it below.

Publisher ID

Turns on Google's Auto Ads (automatic placement — no manual ad-unit setup needed) and generates ads.txt automatically on the next build. Also adds a cookie-use disclosure to the site's Privacy Policy — required by AdSense policy, and only shown while ads are actually on.

Cloud & Login

How publishing works

Every save here writes instantly to your JSONBin.io bin, and the live site reads that bin — so changes appear right away. On top of that, the GitHub Action rebuild bakes the current state directly into index.html for fast first paint and SEO. Create a free bin at jsonbin.io, set its visibility to Public (so the site can read it without exposing your key), then paste the Bin ID below. Your API key stays in this browser only — it is never written to the public site.
